# Student Exam Result Generator 🎓

A JavaScript mini-project that processes an array of student exam results to determine their pass/fail status and calculates the average score of the passing students.

## 🚀 Features
- Evaluates each student's marks against a passing threshold and assigns a "Pass" or "Fail" status.
- Filters the data to extract only the students who passed.
- Calculates the total and average marks of the passing students using `reduce()`.

## 🧠 Concepts Used
- Array Methods (`map`, `filter`, `reduce`)
- Object Destructuring
- Ternary Operators

## 🛠️ How to Run
Run the JavaScript file using Node.js:
```bash
node app.js
